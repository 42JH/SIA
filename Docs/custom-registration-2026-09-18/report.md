# 커스텀 제스처 등록 검사

공개 손 사진 24종을 실제 VIDEO 모델로 각 45프레임 처리하고, 실제 등록 수집→검증→NPZ 업로드 경로를 임시 저장소에서 실행했다. 별도로 저장된 촬영 좌표 50건을 재생했다. 서버·기존 사용자 템플릿에는 쓰지 않았다.

## 수정한 문제

1. **전화 모양(엄지+새끼손가락)이 엄지 올리기로 거절됨.** 원본 모델의 `Thumb_Up` 45회가 그대로 중복 거절을 만들었다. 엄지 후보에서 다른 손가락이 명확히 펴져 있으면 해당 분류를 보류한다. 수정 후 같은 사진은 커스텀 등록에 성공했고, 실제 엄지 올리기/내리기 사진은 계속 기본 동작 중복으로 거절됐다.
2. **손등 브이가 모델의 `None` 분류 때문에 커스텀으로 등록됨.** 검지·중지 펼침, 나머지 손가락 접힘, 엄지 굽힘, 손끝 간격, 두 손가락 방향 차이를 확인해 명확한 브이를 복구한다. `None` 복구 조건은 이미 브이/검지 후보인 경우의 교정보다 엄격하다. 손가락 두 개를 붙인 자세는 계속 커스텀으로 등록된다. 기본 브이는 `Victory` 중복 안내가 정상이다.
3. **같은 정적 자세를 회차별 반대 손으로 찍으면 불일치/큰 분산으로 거절됨.** 실행과 중복 검사에는 좌우 반전 호환이 있었으나 등록 평균에는 없었다. 회차 비교와 분산 계산 전에 특징을 기준 자세의 좌우 방향에 정렬한다. 4개 자세에서 좌우 교대 등록과 양손 인식을 검사했고, 실제로 다른 모양을 섞으면 계속 거절됐다.
4. **모든 회차를 대표할 촬영본이 있는데도 전체 등록을 거절함.** 기존에는 모든 쌍의 거리가 실행 임계값 이하여야 했다. 이제 실제 촬영본 중 하나가 나머지 모든 회차와 임계값 안에서 일치하면 인정한다. 실행 임계값 자체는 유지했다. 고립된 오촬영, 서로 떨어진 두 그룹, NaN 비교는 계속 거절한다. 저장 촬영 `20260916T081425_a3d897a72e3d.npz`의 세 쌍 거리 0.2046/0.1940/0.2947에서 첫 회차가 모두를 대표함에도 거절되던 문제가 해결됐다.

## 결과

| 검사 | 결과 |
| --- | --- |
| 실제 모델을 거친 공개 사진 24종 | 커스텀 13종 등록, 기본 중복 9종 거절, 관측 문제 2종 거절 |
| 등록된 사진 13종 재등록 | 13종 모두 중복 거절 |
| 서로 구별되는 10종을 하나의 저장소에 순차 등록 | 10종 모두 성공 |
| 위 10종 저장 후 인식 및 재등록 | 모두 자기 이름으로 인식, 모두 중복 거절 |
| 좌표/파서/등록/인식 회귀 검사 | 123개 통과, 실패·오류·스킵 0 |
| 앞선 브이→검지 VIDEO 재현 | 교정 후 브이 45/45, 실행 판정은 브이 1회·검지 0회 유지 |
| 사진 변형 708건 | 상세 변경 27건은 `builtin-regression.json`에 기록 |

사진으로 등록된 13종은 전화 모양, 네 손가락, 움켜쥐기, 집기, 검지+새끼손가락, 앞쪽 가리키기, 새끼손가락, 세 손가락 변형 3종, 붙인 두 손가락 앞/뒤, 중지 모양이다. 공개 데이터 이름 기준이며 제품 기본 동작 이름은 아니다.

10종 동시 저장 시험은 한 손 정적 4종, 양손 정적 조합 2종, 한 손 동적 원 그리기/상하 왕복 2종, 양손 모으기/벌리기 2종이다. 공개 사진의 손 좌표에 제어된 궤적을 적용했고 동적 촬영 길이는 회차마다 0.8/1.0/1.2초로 바꿨다. 새 사람이 실제로 촬영한 동작 10종이라는 뜻은 아니다. 정적/동적에 같은 손 모양을 중복 사용하는 경우는 기존 교차 중복 정책에 따라 차단된다.

저장 좌표 50건은 현재 빈 저장소에서 8건 등록·42건 거절됐다. 이전에 저장된 실패 촬영도 포함하므로 42건을 모두 코드 오류로 보지 않는다. 원래 등록 성공했던 10건 중 2건만 현재 품질 기준을 통과했다. 남은 8건은 손 개수 불일치 또는 회차 간 편차로 거절됐으며, 원본 영상 없이 정상 동작이라고 확정하거나 임계값을 느슨하게 만들지 않았다. 기존 기록은 원본 모델 라벨이 없어 기본 동작 중복 여부를 재검증할 수 없다.

관측 문제 2종은 `ok` 사진에서 손 미검출, `mute` 사진에서 두 개의 손 관측/식별 불일치다. 분류 단계에서 없는 손 좌표를 만들어 등록시키지 않았다. 앞선 가로 압축 스트레스 사진의 브이 3건 판정 보류도 남아 있다. 실제 카메라·UI·BE 기능 실행 검사는 이 보고서 범위 밖이다.
