# 커스텀 한 손 정적 제스처의 좌우·손등 비교 일관성

## 변경

별도 브랜치 feature/custom-static-consistency에서 구현했다. 341 세션 갱신 작업은 변경하지 않았다.

기존 한 손 정적 비교는 회전 정렬된 2D 손 좌표와 좌우 반전 거리를 사용했다. 좌우 반전은 이미 지원했지만 실제 손등 관측의 가림·원근 차이를 2D 좌표만으로 안정적으로 처리한다고 보장할 수 없었다.

새 촬영에는 손 관절 21개의 3D 거리 210개와 손바닥 축·엄지의 수직 방향 2개를 표본별로 저장한다. 관절 이름별 거리를 사용하여 손가락 접힘·벌어짐과 엄지 위치를 보존한다. 손끝 간격의 차이가 전체 평균에 묻히지 않도록 별도 최대 오차도 사용한다. 수직 방향은 위·아래를 가리키는 모양을 합치지 않도록 유지한다.

- 좌우 반전과 수직축 중심의 손바닥/손등 회전은 같은 형태로 비교한다. 모든 3차원 회전을 동일시하지 않는다.
- 저장 표본과 입력에 모두 유효한 3D 특징이 있으면 등록 중복 검사와 실행에서 같은 거리 함수를 사용한다.
- 실행 기준 0.35, 등록 중복 기준 0.45는 기존 값을 유지한다. 같은 거리 함수를 사용하되 두 임계값은 목적상 다르다. 이 거리값은 확률이나 정확도가 아니다.
- 등록의 프레임 안정성·회차 일관성도 해당 표본에 모두 3D 정보가 있으면 3D 특징을 사용한다.
- 새 NPZ에 static_shapes/static_shape_valid를 추가하고 캐시 병합 및 이름 교체 시 유지한다.
- 기존 2D NPZ 및 3D 검출 누락은 기존 2D 경로를 사용한다. 기존 자료에서 깊이 정보를 추정해 채우지 않는다.
- 기존 동작 재촬영은 자기 자신을 비교에서 제외한다. 새 이름으로 같은 동작 등록은 기존 클래스와 비교한다.
- 내장 7종 판정 및 정적/동적 교차 검사 자체는 이번 변경에서 수정하지 않았다.

## 적용과 한계

현재 실행 중인 341 AI는 바꾸거나 재시작하지 않았다. 실제 등록 데이터와 기능 매핑도 변경하지 않았다. 이 브랜치의 AI를 실행해야 새 경로가 적용된다. 여러 AI를 동시에 실행하지 않는다.

기존 2D로 저장된 한 손 정적 제스처는 먼저 동작 재촬영으로 유효한 3D 특징을 저장해야 손등 비교 개선을 온전히 적용받는다. 그 후 새 등록에서 반대 손·손등 방향으로 같은 모양을 촬영해 중복 거부를 확인한다. 단순 회전 변환은 실제 카메라의 가림·추적 오류를 재현하지 않으므로 48/48을 라이브 인식률 100%로 해석할 수 없다.

55쌍 평가도 제한된 표본의 결과이며 모든 커스텀 모양의 오거부율을 보장하지 않는다. 새 좌우/손등 촬영에서 동일 동작 차단율, 정상 커스텀 오거부율, 실제 실행 인식률 및 다른 명령 오발동률을 별도로 확인해야 한다. 기존 80% 동적 인식률 목표와는 별개다.

NPZ 추가 필드는 현재 read_templates/캐시 경로에서 지원하고, 기존 2D 특징도 함께 저장한다. 이전 AI가 파일을 읽을 때는 2D 경로로 처리하므로 AI 버전이 섞이면 비교 결과가 달라질 수 있다. 모듈 배포 시 관련 파일을 함께 반영한다.
