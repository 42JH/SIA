# 정적 한 손 제스처 2D와 3D 비교

## 적용 방식

정적 한 손 제스처는 새 촬영에서 2D 특징과 3D 손 모양 특징을 함께 저장합니다. 실행과 등록 중복 검사는 유효한 3D 특징이 있을 때 3D 거리를 사용하고, 3D 데이터가 없으면 기존 2D 경로로 폴백합니다.

2D는 회전 정렬된 21개 랜드마크와 좌우 반전을 비교합니다. 3D는 관절 사이 거리, 손가락 끝 간격, 손바닥·엄지 방향을 비교하므로 손등 방향과 깊이에서 생기는 투영 차이를 보완합니다. 위·아래 방향처럼 의미가 다른 방향은 합치지 않습니다.

## 정량 결과

내장 손 모양 테스트 데이터 16종을 대상으로 좌우 반전과 3가지 3D 회전·이동 변환을 적용했습니다. 서로 다른 손 모양 11종의 55쌍도 비교했습니다. 등록 중복 임계값은 0.45, 실행 임계값은 0.35이며 점수는 확률이 아니라 거리입니다.

| 지표 | 2D | 3D |
|---|---:|---:|
| 변환된 동일 형태 매칭 | 16/16 | 48/48 |
| 서로 다른 형태 쌍 | 55 | 55 |
| 잘못된 중복 판정 | 0쌍 | 0쌍 |
| 가장 가까운 다른 형태 거리 | 0.5585 | 0.4783 |
| 비교 중앙값 | 0.0506ms | 0.0245ms |
| 비교 95백분위 | 0.2088ms | 0.1012ms |

원자료는 [static-2d-vs-3d-evaluation.json](static-2d-vs-3d-evaluation.json)입니다. `python evaluate_static_2d_vs_3d.py`로 재현할 수 있습니다.

## 판단

현재 제한된 데이터에서는 두 방식 모두 서로 다른 55쌍을 잘 분리했습니다. 2D는 계산량이 작고 기존 템플릿과 호환되며, 3D는 손등·깊이·가림으로 2D 투영이 달라지는 경우에 더 유리합니다. 따라서 3D 단독으로 교체하지 않고 **유효한 3D가 있을 때 3D를 사용하고, 없으면 2D로 폴백하는 방식**이 적절합니다.

3D는 MediaPipe world landmark가 안정적으로 검출될 때만 의미가 있습니다. 기존 2D 템플릿은 재촬영해야 3D 비교를 사용합니다. 이번 결과는 저장 좌표와 합성 변환 검증이므로 실제 좌우 손·손등 카메라 인식률을 의미하지 않습니다. 실제 촬영에서 동일 동작 중복 거부율, 정상 동작 오거부율, 실행 인식률, 오발동률을 별도로 측정해야 합니다.
